Montée en charge d'un parcours de réservation

                SLA < 2 s
              

              
Des utilisateurs virtuels recherchent, choisissent et paient un vol. La charge est paramétrable et un tableau de bord HTML est généré.

              
    
                
  • Données variables via un fichier CSV
    • 
                
  • Corrélation : prix extrait de la réponse précédente
    • 
                
  • Transaction pour mesurer le parcours complet
    • 
              

              

                Plan de test
              

            

            
# 25 utilisateurs, montée en 60 s, 5 itérations
jmeter -n -t blazedemo-reservation.jmx \
       -Jusers=25 -Jrampup=60 -Jloops=5 \
       -l resultats.jtl -e -o rapport

# Scénario par utilisateur virtuel
#  01 GET  /                  → "Welcome to the Simple Travel Agency!"
#  02 POST /reserve.php       → départ / destination lus dans trajets.csv
#  03 POST /purchase.php      → prix corrélé : name="price" value="(.+?)"
#  04 POST /confirmation.php  → "Thank you for your purchase today!"
#  SLA : chaque page < 2000 ms · réflexion 1 à 3 s
